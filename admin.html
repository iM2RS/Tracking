إعدادات الربط

أول مرة بس: راح تحتاج تسوي "توكن" وحدة من حسابك بـ GitHub تسمح للوحة بالنشر مباشرة.

شلون أسوي التوكن؟ (خطوات مرة وحدة)
1. روح لـ GitHub.com → اضغط صورتك بالزاوية → Settings
2. تحت لين آخر القائمة الجانبية: Developer settings
3. Personal access tokens → Fine-grained tokens → Generate new token
4. اختار اسم أي شي، وتحت Repository access اختار Only select repositories وحدد مستودعك (مثلاً Tracking)
5. تحت Permissions → Repository permissions → دوّر على Contents وخله Read and write
6. انزل وكبس Generate token، وانسخ التوكن (يبدأ بـ github_pat_) — GitHub يوريه لك مرة وحدة بس
7. الصقه بخانة "التوكن" تحت، واكتب اسم المستودع بصيغة username/repo-name، ثم احفظ الإعدادات

⚠️ التوكن مثل كلمة سر لحسابك — يُحفظ فقط بمتصفحك أنت (ما يروح لأي مكان آخر) لكن لا تشارك رابط لوحة الأدمن أو هذا الجهاز مع أي شخص غير موثوق. تكدر تلغيه بأي وقت من نفس صفحة Tokens بـ GitHub.
